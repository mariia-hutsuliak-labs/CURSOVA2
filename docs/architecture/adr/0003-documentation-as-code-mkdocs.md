# ADR-0003: Documentation as Code: MkDocs Material і strict-збірка в CI

- **Номер:** 0003
- **Статус:** Accepted (прийнято)
- **Дата фіксації:** 2026-11-17
- **Власник:** Mariia Hutsuliak
- **Пов'язані рішення:** [ADR-0002](0002-flask-monolith-with-json-api.md), [ADR-0004](0004-api-first-openapi-contract.md)

## Контекст

Після аудиту ЛР10 документація (SDD, ISD, ADR) лежить у репозиторії як окремі Markdown-файли без єдиної точки входу, без перевірки посилань і без автоматичної публікації. Дрейф документації виявляється лише скриптом `scripts/doc-audit.sh`, який запускається вручну.

## Розглянуті альтернативи

| Альтернатива | Плюси | Мінуси |
|---|---|---|
| Документація у Word/Confluence/Notion | зручний редактор | немає версіонування разом із кодом, немає рев'ю через pull request, дрейф між кодом і текстом |
| GitHub Wiki | вбудований у GitHub | окремий репозиторій, немає збірки й перевірки посилань |
| Docusaurus / Sphinx | потужні генератори | потребують Node.js або reStructuredText, а вся документація проєкту вже в Markdown |
| **MkDocs Material + GitHub Actions + GitHub Pages** | Markdown як є, Python-стек, як у проєкту, режим `--strict`, безкоштовна публікація | менше можливостей для кастомізації, ніж у Docusaurus |

## Рішення

Ставитися до документації як до коду: Markdown у `docs/`, збірка MkDocs Material, обов'язкова збірка `mkdocs build --strict` у CI перед публікацією на GitHub Pages, власники документів через `CODEOWNERS`, паспорти front matter (`owner`, `status`, `review_date`) для автоматичного аудиту актуальності.

## Наслідки

- (+) Дефект документації (мертве посилання, сторінка поза навігацією) зупиняє публікацію так само, як червоний тест зупиняє реліз.
- (+) Зміна документації проходить рев'ю власника через `CODEOWNERS`.
- (+) Дата останнього редагування береться з Git, а не вказується вручну.
- (−) Нова залежність у CI (`requirements-docs.txt`) і додатковий конвеєр, який треба підтримувати.
- (−) Strict-режим робить збірку чутливою до дрібних помилок розмітки; це прийнята ціна за якість.
